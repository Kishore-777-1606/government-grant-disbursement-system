# Approval Logic

## Introduction

The Approval process determines whether a verified application should receive the government grant.

## Approval Process

### Step 1

The Finance Officer receives the verified application.

### Step 2

The Finance Officer reviews:

- Verification Report
- Applicant Details
- Scheme Information
- Required Documents

### Step 3

The system checks whether sufficient budget is available for the scheme.


### If Budget is Available

- The application is approved.
- The application status is updated.
- An approval record is created.
- The application is forwarded to the Disbursement stage.


### If Budget is Not Available

- The application is rejected or placed on hold.
- The beneficiary is notified about the decision.


## Result

Approved applications proceed to the Disbursement Workflow, while rejected applications are closed or held until further action.
