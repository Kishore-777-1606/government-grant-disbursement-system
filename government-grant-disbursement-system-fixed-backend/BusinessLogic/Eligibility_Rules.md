# Eligibility Rules

## Introduction

The Eligibility Rules determine whether a beneficiary qualifies to apply for a government scheme. The system checks the applicant's information against the conditions defined for the selected scheme.


## Eligibility Rules

### Rule 1: Age

The applicant must meet the age requirement specified by the scheme.

**Example:**
- Minimum Age: 18 years
- Maximum Age: 60 years

### Rule 2: Income

The applicant's annual income should not exceed the limit specified by the government scheme.


### Rule 3: Citizenship

Only Indian citizens are eligible to apply.


### Rule 4: Residence

The applicant must belong to the state or district where the scheme is available.

### Rule 5: Category

Some schemes are available only for specific categories such as SC, ST, OBC, EWS, or General.


### Rule 6: Required Documents

The applicant must upload all mandatory documents such as:

- Aadhaar Card
- Income Certificate
- Address Proof
- Bank Passbook
- Passport Size Photo

### Rule 7: Duplicate Applications

A beneficiary cannot apply multiple times for the same scheme while an existing application is still under processing.


## Result

If all eligibility conditions are satisfied, the application is forwarded to the Verification stage.

Otherwise, the application is rejected and the beneficiary is informed.
